# 🌍 Youth Map Lab — Roadmap (2025–2027)

Youth Map Lab was originally created to help the National 4-H Geospatial Leadership Team meet partnership goals with NC A&T and Google.  
It has since grown into something bigger:

- A teacher-friendly GIS toolkit any classroom can run in 45–90 minutes  
- A UDL-aligned resource library for multiple subjects and grade levels  
- A student-built model that supports WCPSS as they roll out ArcGIS access districtwide in 2026–27  
- A national plug-and-play geospatial learning system for schools, clubs, and community centers

Youth Map Lab’s long-term goal is to become **the most accessible geospatial education library in the country.**

---

# Roadmap
Simple, transparent checklists for where we’re headed.

---

## **Phase 1 — Foundation (Now → December 2025)**  
**Goal:** Build a unified, district-ready toolkit.

### Infrastructure  
- [ ] Reorganize GitHub using the new folder tree  
- [ ] Add clear README + mission statement  
- [ ] Create standard templates for:
  - [ ] Teacher Guides  
  - [ ] Student Handouts  
  - [ ] StoryMap Templates  
  - [ ] UDL & Accessibility pages  
- [ ] Add example demos + sample StoryMaps  
- [ ] Add contributor guidelines for new student team members  

### Core Modules to Finish  
- [ ] Marine Science Module  
- [ ] Business Planning Module (Business Analyst + site selection)  
- [ ] ELA / Literature Mapping Module  
- [ ] LEGO Engineering + GIS Module  

---

## **Phase 2 — Classroom Alignment (Jan 2026 → April 2026)**  
**Goal:** Align Youth Map Lab to WCPSS and NC Standards.

### Standards + UDL  
- [ ] Add NC Standard Course of Study links (ELA, Science, SS, CTE)  
- [ ] Add grade-band versions (K–5, 6–8, 9–12)  
- [ ] Add UDL variations for each module  
- [ ] Add 45-minute, 60-minute, and 90-minute lesson options  

### Classroom-Ready Materials  
- [ ] Teacher slide decks  
- [ ] Print + digital student worksheets  
- [ ] “No-tech / low-tech / high-tech” versions for each lesson  

---

## **Phase 3 — Apps, StoryMaps & Showcases (May 2026 → September 2026)**  
**Goal:** Publish fully reusable examples that any school can clone.

- [ ] Publish StoryMap templates for every module  
- [ ] Publish Express Maps starter files  
- [ ] Publish ready-to-use ArcGIS apps (e.g., sea level, land cover, business sites)  
- [ ] Upload video walkthroughs for teachers  
- [ ] Create a “Student Work Showcase” folder  

---

## **Phase 4 — Nationalization + Training (Fall 2026–2027)**  
**Goal:** Make Youth Map Lab adoptable by schools across the U.S.

- [ ] Build a Teacher Training Guide  
- [ ] Create PD workshop decks for districts  
- [ ] Add Spanish-language versions of all materials  
- [ ] Add “Start a Youth Map Lab Chapter” onboarding kit  
- [ ] Build a national project library with contributed student work
